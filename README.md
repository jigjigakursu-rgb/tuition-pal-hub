# Tuition Pal

Build the Tuition Tracker (Talebe ve Aidat Takip Paneli) app matching the repository https://github.com/fatihsulxan-ui/tuition-tracker.git: student lists and profiles (talebeler), tuition/fee tracking (AidatPanel, AidatHatirlatma), group filters, reminders, and report exports.

This project was built with [Lovable](https://lovable.dev).
